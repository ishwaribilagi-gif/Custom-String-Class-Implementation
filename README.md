# Custom String Class Implementation in Modern C++

## 📌 Project Overview

This project implements a custom String Class in C++ without using the built-in `std::string` class.

It demonstrates how strings can be managed using dynamic memory allocation, pointers, constructors, destructors, copy and move semantics, and operator overloading.

The main objective is to understand how string operations work internally and how memory is managed in C++.

## ✨ Features

* Default Constructor
* Parameterized Constructor
* Copy Constructor
* Copy Assignment Operator
* Move Constructor
* Move Assignment Operator
* Destructor
* String Length Calculation
* Empty String Checking
* String Concatenation (`+`)
* Equality Operator (`==`)
* Inequality Operator (`!=`)
* Character Access and Modification (`[]`)
* String Append (`+=`)
* Lexicographical Comparison (`<`, `>`)
* C-style String Access (`c_str()`)
* Character Searching (`find()`)
* Substring Extraction (`substr()`)
